# RSEQ Team Calendar

**FR** — Lit le calendrier et le classement d'une ou de plusieurs équipes du RSEQ (pages de ligue
`rseqqca.com` ou ancien site `diffusion.rseq.ca`) et les publie dans Home Assistant sous forme de capteurs
MQTT : statut, prochain match, classement et dernier match. Le rythme de lecture s'accélère les jours de
match. Configuration et capteurs : onglet **Documentation**, ou <https://github.com/Frazou1/rseq_calendar>.

**EN** — Reads the schedule and standings of one or more RSEQ teams (`rseqqca.com` league pages or the old
`diffusion.rseq.ca` site) and publishes them to Home Assistant as MQTT sensors: status, next game,
standings and last game. Updates run more often on game days. Configuration and sensors: **Documentation**
tab, or <https://github.com/Frazou1/rseq_calendar>.
